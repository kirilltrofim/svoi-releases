## Как установить

1. Нажмите «Скачать APK» и на странице выпуска выберите файл, который заканчивается на `.apk`.
2. Откройте файл на телефоне. Если Android спросит, разрешите установку из этого источника.
3. Войдите или присоединитесь к семье по коду.

## Обновления

Приложение само предложит новую версию: над меню появится «Обновить». Новая версия ставится поверх прежней, данные остаются.

<details>
<summary>Проверить, что файл не изменён</summary>

Рядом с APK лежит файл `.sha256` с контрольной суммой. Сравните её с той, что покажет компьютер:

- Windows: `certutil -hashfile SVOI-v0.48.0.apk SHA256`
- macOS и Linux: `shasum -a 256 SVOI-v0.48.0.apk`

</details>
